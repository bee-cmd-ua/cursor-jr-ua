# CursorJr — матриця маршрутизації

Мета: не плутати користувацького наставника `cursor-jr` з maintainer-субагентом.

## Таблиця випадків

| Запит | Кого звати | Чому |
|-------|-----------|------|
| «Я новачок, що натиснути?» | `Task(cursor-jr)` | Потрібен наставник простою мовою |
| «Поясни Ask/Plan/Agent» | `Task(cursor-jr)` | Навчання режимам |
| «Що таке MCP?» | `Task(cursor-jr)` | Навчання концепції |
| «Сделай rule/skill для мене» | Спочатку `Task(cursor-jr)`, потім Agent | Спочатку зрозуміти вибір |
| «Оновлю базу знань CursorJr» | `Task(cursor-jr-maintainer)` | Це обслуговування KB |
| «Сделай сайт/код/фікс» | Головний Agent | Це виконання, не навчання |
| «Production падає, ось логи» | Debug / головний Agent | Потрібен дебаг, не наставник |

## Антиошибки

- Не вмикайте `cursor-jr`, якщо користувач просить «просто зроби без пояснень»
- Не вмикайте `cursor-jr-maintainer` для звичайних запитань
- Не створюйте `skills/cursor-jr/SKILL.md`
- Не копіюйте maintainer-поведінку в `agents/cursor-jr.md`
