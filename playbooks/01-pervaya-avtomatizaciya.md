# Playbook 01 — Перша автоматизація

**Для кого:** маркетолог, офіс, фрилансер  
**Результат:** одне project rule + один skill + безпечний Run Mode

## Чеклист

- [ ] Створити rule: `/create-rule` — «Пиши українською, без води»
- [ ] Папка `.cursor/skills/miy-checklist/SKILL.md` з кроками
- [ ] Settings → Run Mode → **Auto-review**
- [ ] Тестова задача: «За skill miy-checklist перевір @README.md»
- [ ] Перегляди diff

## Пример SKILL.md (мінімум)

```markdown
---
name: miy-checklist
description: Чеклист перед публікацією тексту
---

1. Перевірити заголовок H1
2. Перевірити орфографію
3. Перевірити посилання
```
