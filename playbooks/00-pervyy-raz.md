# Playbook 00 — Перший раз у Cursor

**Для кого:** день 1, будь-яка професія  
**Результат:** відкрита папка, перший діалог з Agent, одна безпечна правка, перегляд diff

## Чеклист

- [ ] Скачати і встановити Cursor
- [ ] Увійти в акаунт
- [ ] Створити папку проєкту і **File → Open Folder**
- [ ] `Ctrl+I` — відкрити Agent
- [ ] Режим **Ask**: «Поясни цю папку простою мовою»
- [ ] Режим **Agent**: «Запропонуй одне безпечне поліпшення. Чекай мого вибору»
- [ ] Вибрати одне пропозицію
- [ ] Перегляди **diff** — зелене/червоне
- [ ] Прийняти або відхилити правку
- [ ] Якщо не подобалось — **Restore Checkpoint**

## Промпти (копіювати)

**Ask:**
```
Поясни цю кодову базу простою мовою. Що тут головне?
```

**Agent:**
```
Запропонуй три маленькі безпечні поліпшення. Поясни кожне. Чекай, поки я виберу одне.
```
