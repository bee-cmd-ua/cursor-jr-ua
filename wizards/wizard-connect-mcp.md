# Wizard — підключити MCP

## Шаги

1. Назвіть сервіс: браузер, docs, CMS, CRM тощо
2. Знайдіть офіційну інструкцію MCP
3. Перевірте, чи потрібні API keys
4. Секрети храніть в env, не в Git
5. Додайте MCP конфігурацію
6. Перезапустіть Cursor
7. Перевірте в Agent: «Які MCP tools доступні?»

## Готовий промпт

```text
Помоги підключити MCP для [сервіс]. Поясни простою мовою. Спочатку перевір, які секрети потрібні.
```
