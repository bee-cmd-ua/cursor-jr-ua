# Wizard — перша автоматизація

## Шаги

1. Опишіть повторюване завдання одним реченням
2. Визначте: це стандарт поведінки чи пошаговий рецепт?
3. Якщо стандарт — створіть rule
4. Якщо рецепт — створіть skill
5. Протестуйте вручну в Agent
6. Тільки потім думайте про Automations

## Готовий промпт

```text
Я хочу автоматизувати повторюване завдання: [опис].
Спочатку помоги вирішити, потрібен rule, skill, MCP чи automation. Не створюй файли, поки я не підтвержу.
```
