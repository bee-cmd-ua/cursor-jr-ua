# Wizard — Canvas і Shared Canvas

## Шаги

1. Сформулюйте, який звіт потрібен
2. Попросіть Agent: «Зроби це у Canvas»
3. Перевірте дані
4. Якщо потрібна ссилка команді — ищите Publish
5. При необхідності надішліть скриншот
6. Не діліться звітом до перевірки цифр

## Готовий промпт

```text
Зроби Canvas-звіт по темі [тема]. Він повинен бути зрозумілий людині без розробки: заголовки, таблиця, висновки.
```
