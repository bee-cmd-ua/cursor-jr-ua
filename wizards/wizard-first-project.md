# Wizard — перший проєкт

## Шаги

1. Відкрийте папку проєкту у Cursor
2. Ask: «Поясни структуру цієї папки простою мовою»
3. Попросіть карту головних файлів
4. Виберіть одну маленька правку
5. Agent: «Зроби тільки цю правку»
6. Перевірте diff
7. Якщо не подобалось — Restore Checkpoint

## Готовий промпт

```text
Я новачок. Поясни цю папку простою мовою: що тут головне і які 3 файли відкрити першими. Запропонуй одну безпечну правку для тренування. Поки нічого не змінюй.
```
