# Wizard — виправити помилку

## Шаги

1. Скопіюйте точний текст помилки
2. Опишіть, що робили перед помилкою
3. Переключіться в Debug Mode
4. Попросіть спочатку знайти причину
5. Дозволяйте тільки зрозумілі діагностичні команди

## Готовий промпт

```text
У мене помилка: [текст помилки].
Я зробив: [кроки].
Знайди причину. Сначала не змінюй файли.
```
