## Простими словами

**API** — програмний доступ до даних Cursor для скриптів і дашбордів. Більшість API — для **команд Enterprise**.

## Не лякайтесь у день 1

Новачку достатньо Agent в інтерфейсі. API — коли автоматизуєте на рівні компанії.

## Що є (коротко)

| API | Кому |
|-----|------|
| Admin / Analytics | Enterprise команди |
| Cloud Agents API | Бета, автоматизація агентів |
| TypeScript / Python SDK | Розробники інтеграцій |

## Аутентифікація

API-ключ у Dashboard → API Keys. Формат `crsr_...`. Не кладіть ключ у Git.

## Коли повернутись сюди

- Вже впевнено працюєте в Agent
- Потрібен дашборд використання команди
- Потрібні агенти за розкладом через API
