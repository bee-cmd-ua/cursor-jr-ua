## Простими словами

**Контрольна точка** — знімок файлів до того, як Agent щось змінив. Як «скасувати» у Word, але для всього проєкту одразу.

## Коли вам це потрібно

Agent зробив не те — хочете повернути як було.

## Покроково

1. Agent автоматично створює checkpoint перед великими правками
2. У стрічці чату видно точки на часовій шкалі
3. Наведіть на **попереднє повідомлення** → **Відновити контрольну точку**
4. Або натисніть **Restore Checkpoint** у повідомлення
5. Всі файли повернуться до стану на той момент

## Аналогія

Фотографія столу до прибирання. Не сподобалось — розклали все як на фото.

## Важливо

- Checkpoints **локальні**, це не Git
- Для постійної історії використовуйте Git (якщо знайомі)
- Checkpoints тільки для скасування роботи Agent

## Перевірка

Після Restore файли в редакторі мають збігатися з тим, що було до правки.

## Часті помилки

- Плутають з Git revert — checkpoint не коміт
- Відновили надто стару точку — втратили потрібні правки
