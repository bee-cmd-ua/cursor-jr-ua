# Prompting — як ставити завдання Cursor

## Простими словами

Промпт — це технічне завдання. Чим ясніше ви описали результат і обмеження, тим менше Agent буде гадати.

## Формула хорошого промпту

```text
Мета: що має вийти.
Контекст: які файли дивитись через @.
Обмеження: що не чіпати.
Перевірка: як зрозуміти, що готово.
```

## Приклад

```text
@src/pages/home.tsx
Мета: замінити текст у hero-блоці на більш зрозумілий для новачків.
Обмеження: не змінювати стилі і компоненти.
Перевірка: покажи diff і поясни, що змінив.
```

## Часті помилки

- «Зроби красиво» без критеріїв
- Не вказали файли через `@`
- Не сказали, що не можна чіпати
- Змішали текст, дизайн і деплой в один запит
