# Debug Mode — розбір складних помилок

## Простими словами

Debug Mode — режим для ситуацій «щось зламалось, незрозуміло де». Agent збирає факти: помилки, логи, поведінку застосунку.

## Коли обирати Debug

- Є помилка, але причина незрозуміла
- Тести падають
- Застосунок запускається, але працює дивно
- Потрібна перевірка в браузері або терміналі

## Покроково

1. Переключіться в Debug
2. Дайте точний симптом: що натиснули, що очікували, що отримали
3. Вставте помилку або лог
4. Дозволяйте тільки зрозумілі діагностичні команди
5. Попросіть: «Спочатку знайди причину, потім запропонуй мінімальний фікс»

## Хороший промпт

```text
Кнопка відправки форми нічого не робить. Знайди причину через Debug Mode, але спочатку не змінюй файли.
```

## Часті помилки

- Просити «виправ все» без опису симптому
- Не прикладати текст помилки
- Схвалювати небезпечні команди замість діагностики
