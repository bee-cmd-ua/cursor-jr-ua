# Agents Window — вікно агентів

## Простими словами

Agents Window — місце, де ви відкриваєте і ведете чати з Agent, переключаєте завдання і працюєте з кількома агентними сесіями.

## Коли вам це потрібно

- Створити новий чат Agent
- Повернутися до минулого завдання
- Відкрити canvas або вкладку агента
- Розділити різні завдання по різних сесіях

## Правило для новачка

Одне велике завдання — один окремий чат. Не змішуйте «поясни проєкт», «зроби форму» і «запусти деплой» в одній довгій розмові.

## Покроково

1. Відкрийте Agents Window
2. Створіть новий агентний чат для нового завдання
3. Назвіть завдання зрозумілим першим повідомленням
4. Якщо тема змінилась — краще новий чат
5. Старі чати використовуйте як історію, але не як нескінченну пам'ять

## Часті помилки

- Продовжувати нову тему в старому чаті
- Втрачати контекст, бо не вказали файли через `@`
- Очікувати, що Agent пам'ятає всі минулі проєкти
