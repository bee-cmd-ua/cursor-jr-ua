# Agent Review — як перевіряти зміни агента

## Простими словами

Agent Review — це звичка не приймати роботу AI наосліп: подивитися diff, запустити перевірки і зрозуміти, що змінилось.

## Міні-чеклист

- Що змінилось у файлах?
- Є зайві правки?
- Не видалено важливі рядки?
- Пройшли тести або збірка?
- Agent пояснив, чому так зробив?

## Покроково

1. Після роботи Agent відкрийте diff
2. Перегляньте кожен змінений файл
3. Попросіть: «Поясни ці зміни простими словами»
4. Запустіть перевірки проєкту
5. Якщо не подобається — відхиліть файл або відновіть checkpoint

## Хороший промпт

```text
Перш ніж я прийму diff, поясни по файлах: що змінено, навіщо і які ризики перевірити.
```
