# Ask Mode — запитати без правок

## Простими словами

Ask Mode — режим «поясни і покажи», де Cursor читає проєкт, але не змінює файли.

## Коли обирати Ask

- Ви вперше відкрили чужий проєкт
- Потрібно зрозуміти архітектуру
- Хочете запитати «де що лежить»
- Боїтесь випадкових змін

## Покроково

1. Переключіться в Ask
2. Вкажіть файл або папку через `@`
3. Запитайте простою мовою
4. Попросіть карту файлів або коротке пояснення
5. Якщо готові до правок — переходьте в Plan або Agent

## Приклад

```text
@src/ Поясни структуру проєкту для новачка. Нічого не змінюй.
```
