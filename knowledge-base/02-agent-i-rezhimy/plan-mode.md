# Plan Mode — спочатку план, потім правки

## Простими словами

Plan Mode — режим, де Cursor спочатку досліджує завдання і пише план. Правки починаються тільки після вашого схвалення.

## Коли обирати Plan

- Завдання зачіпає кілька файлів
- Є кілька варіантів реалізації
- Ви хочете спочатку зрозуміти, що Agent збирається робити
- Потрібно узгодити підхід перед кодом

## Покроково

1. Переключіться в Plan
2. Опишіть результат, а не тільки дію
3. Дайте обмеження: «не чіпати оплату», «без публікації»
4. Прочитайте план
5. Поставте запитання або попросіть спростити
6. Схваліть план
7. Після правок перевірте diff

## Часті помилки

- Схвалювати план, не читаючи
- Змішувати кілька завдань в одному
- Просити одразу код у Plan і чекати миттєвих правок
