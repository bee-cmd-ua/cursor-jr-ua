# Design Mode — правки інтерфейсу через виділення

## Простими словами

Design Mode допомагає правити інтерфейс візуально: ви показуєте Cursor, що саме на екрані треба змінити, а не описуєте все словами.

## Коли це потрібно

- Потрібно поправити UI
- Важко пояснити елемент словами
- Потрібно вказати конкретний блок на сторінці або canvas

## Аналогія

Як дати дизайнеру скриншот і обвести червоним: «ось цей блок зробити ширшим».

## Покроково

1. Відкрийте сторінку або canvas
2. Увімкніть Design Mode, якщо він доступний
3. Виділіть потрібний елемент
4. Напишіть коротку правку
5. Перевірте diff і візуальний результат

## Часті помилки

- Просити «зроби красиво» без конкретного елемента
- Не перевіряти адаптив після візуальної правки
- Плутати Design Mode з повноцінним Figma
