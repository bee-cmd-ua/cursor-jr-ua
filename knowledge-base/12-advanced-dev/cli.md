# Cursor CLI і headless-режим

## Простими словами

CLI — спосіб запускати Cursor/Agent з командного рядка, без звичайного інтерфейсу IDE.

## Коли це потрібно

- Автоматизація в CI/CD
- Скрипти розробників
- Headless-завдання без вікна Cursor
- Інтеграції з GitHub Actions

## Чому не для першого дня

CLI потребує розуміння терміналу, git, окруження і прав доступу. Новачку краще починати з Agent в IDE.
