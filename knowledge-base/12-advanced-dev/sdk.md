# Cursor SDK — TypeScript і Python

## Простими словами

SDK — набір бібліотек, щоб запускати агентів Cursor з власного коду: TypeScript або Python.

## Коли це потрібно

- Ви будуєте свій інструмент поверх Cursor
- Потрібно програмно запускати агента
- Є backend/скрипт/пайлайн

## Чому це продвинутий рівень

Потрібні навички програмування, API-ключі та розуміння окружень. Звичайному новачку SDK не потрібен.
