# Cloud Agents API

## Простими словами

Cloud Agents API дозволяє створювати та управляти хмарними агентами програмно: через HTTP-запити і API-ключи.

## Коли це потрібно

- У компанії є свій портал завдань
- Потрібно запускати агентів по подіям
- Потрібна інтеграція з внутрішніми системами

## Не для першого дня

Якщо ви щойно почали з Cursor, API не потрібен. Спочатку: Agent в IDE → Rules/Skills → MCP → Cloud Agents → тільки потім API.

## Безпека

- API-ключи не зберігати в Git
- Мінімальні права доступу
- Ліміти і обробка 429
- Логи помилок
