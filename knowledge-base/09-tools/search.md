# Search tool — пошук по проєкту

## Простими словами

Search tool допомагає Agent швидко знайти потрібні файли, функції і місця в коді без ручного перегляду всіх папок.

## Коли вам це потрібно

- «Де знаходиться головна сторінка?»
- «Знайди форму реєстрації»
- «Де використовується цей текст?»
- «Покажи, які файли відповідають за оплату»

## Два види пошуку

| Вид | Простими словами | Коли корисно |
|-----|-----------------|-------------|
| Semantic search | За змістом | «Де логіка входу?» |
| Точний пошук | За словами | «Знайди `submitForm`» |

## Хороший промпт

```text
Знайди, де в проєкті реалізована форма зворотного зв'язку. Спочатку тільки поясни файли, нічого не змінюй.
```

## Часті помилки

- Просити одразу править, не зрозумівши структури
- Не уточнити, що потрібно тільки знайти
- Давати надто широкий запит «перевір весь проєкт»
