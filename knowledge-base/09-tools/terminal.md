# Terminal tool — команди у Cursor

## Простими словами

Terminal tool — це коли Agent може запускати команди в терміналі: встановити залежності, запустити тести, зібрати проєкт.

## Коли вам це потрібно

- Перевірити, чи працює проєкт
- Запустити `npm install`, `npm test`, `npm run build`
- Подивитися помилки після запуску застосунку

## Аналогія

Термінал — як пульт управління майстернею. Agent може натискати кнопки, але небезпечні кнопки краще підтверджувати вручну.

## Покроково

1. Попросіть Agent: «Запусти перевірки проєкту»
2. Agent запропонує команду
3. Прочитайте, що команда робить
4. Якщо команда зрозуміла — дозвольте
5. Якщо незрозуміла — спитайте: «Поясни команду простими словами»
6. Після виконання попросіть Agent коротко пояснити результат

## Безпека

Новачкам краще тримати **Auto-review**. Не вмикайте **Run Everything**, поки не розумієте наслідків.

## Часті помилки

- Схвалювати команди видалення, не читаючи
- Запускати install/build не з тієї папки
- Не дивитись на вихід помилок
