## Простими словами

Що робити, якщо Agent «застряг», робить не те або закінчився ліміт.

## Agent ходить по колу

1. Натисніть **Stop**
2. **Новий чат**
3. Звузьте завдання: одна мета, один файл
4. Спробуйте **Plan** замість Agent

## Scope creep (робить забагато)

- Явно: «Тільки файл X, не чіпай решту»
- Використовуйте `@file`

## Контекст переповнився

- Новий чат
- Коротке резюме в першому повідомленні
- Subagent Explore для пошуку

## Ліміти запитів (тариф Hobby)

- Менше паралельних завдань
- Дивіться `08-help-faq/pricing-i-limity.md`

## Команда в терміналі небезпечна

- Відхиліть
- Спитайте: «поясни команду простими словами»
