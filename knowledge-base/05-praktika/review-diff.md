## Простими словами

**Diff** — екран «було / стало». Зелене — додано, червоне — видалено.

## Коли вам це потрібно

Після кожної роботи Agent — до того як сказати «готово».

## Покроково

1. Agent вносить правки — відкриється панель змін
2. Перегляньте кожен файл
3. **Accept** — прийняти файл або всі
4. **Reject** — відхилити
5. Незрозуміло? Спитайте в Ask: «поясни цю правку в @file»

## Аналогія

Редактор надіслав правки в договір — ви порівнюєте версії track changes.

## Часті помилки

- Accept All не дивлячись — ризик зайвого коду
- Не помітили видалення важливого рядка
