# Bugbot і Security Agents

## Простими словами

Bugbot і Security Agents — помічники для командної перевірки коду: знайти баги, ризики безпеки і проблеми в PR.

## Коли це потрібно

- Є pull request
- Потрібне незалежне ревью
- Проєкт пов'язаний з auth, платежами, особистими даними
- Команда хоче автоматичну перевірку перед merge

## Новачку важливо

Це не заміна вашому diff review. Спочатку навчіться перевіряти зміни Agent, потім підключайте Bugbot на PR.

## Часті помилки

- Вважати Bugbot гарантією відсутності багів
- Ігнорувати human review
- Запускати security review без опису контексту
