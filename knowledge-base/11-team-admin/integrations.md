# Integrations — зовнішні сервіси

## Простими словами

Integrations підключають Cursor до сервісів команди: GitHub, Slack, GitLab, Linear, Jira, Notion та інших.

## Коли це потрібно

- Agent повинен працювати з GitHub issue або PR
- Потрібні сповіщення в Slack
- Команда веде завдання в Linear/Jira
- Потрібно зв'язати Cursor з робочими процесами компанії

## Чим відрізняється від MCP

| MCP | Integrations |
|-----|--------------|
| Інструменти і дані для агента | Підключення сервісів акаунту/команди |
| Часто налаштовується в проєкті | Часто налаштовується в Dashboard |
| Може бути кастомним | Зазвичай офіційний коннектор |

## Для новачка

Не підключайте все одразу. Підключайте тільки сервіс, який потрібен для конкретного завдання.
