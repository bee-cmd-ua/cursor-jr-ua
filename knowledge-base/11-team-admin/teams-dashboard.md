# Teams і Dashboard

## Простими словами

Dashboard — кабінет команди Cursor: учасники, витрати, shared canvases, integrations, API keys і налаштування організації.

## Коли вам це потрібно

- Перевірити, чи є ви в team
- Налаштувати Shared Canvases
- Подивитися usage/spending
- Управляти учасниками
- Увімкнути інтеграції

## Що пояснювати новачку

Якщо людина одна, їй часто вистачає особистого Cursor. Team потрібен, коли є колеги, спільний доступ, billing або shared features.

## Часті місця

| Розділ | Навіщо |
|--------|--------|
| Members | Хто в команді |
| Usage / Spending | Витрати і ліміти |
| Shared Canvases | Опубліковані canvas |
| Integrations | GitHub, Slack та ін. |
| API Keys | Ключи для API |
