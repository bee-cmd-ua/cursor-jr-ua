# Pricing, usage limits і моделі

## Простими словами

Cursor рахує використання Agent і моделей. На безкоштовному тарифі лімітів менше, на Pro/Teams/Enterprise — більше можливостей.

## Що важливо новачку

- Якщо Agent перестав відповідати або просить почекати — можливо, ліміт
- Auto-модель часто економить витрату
- Max Mode і важкі моделі можуть витрачати більше
- Usage дивіться в Dashboard

## Що запитувати у CursorJr

```text
Поясни мої ліміти Cursor простими словами і де їх подивитися.
```

## Часті помилки

- Думати, що всі моделі коштують однакові
- Запускати великі завдання без Plan
- Не дивитись на usage dashboard
