## Простими словами

**@** у чаті Agent — спосіб сказати «дивись сюди»: файл, папка, правило, документація.

## Коли вам це потрібно

Agent не вгадує, який файл важливий — вкажіть явно.

## Приклади

- `@index.html` — цей файл
- `@src/components/` — папка
- `@my-rule` — правило з rules
- `@Docs` — документація (якщо підключена)

## Покроково

1. У полі Agent почніть писати `@`
2. Виберіть зі списку файл або папку
3. Допишіть завдання: «Виправ помилку в заголовку»

## Ефективний промпт

```
@README.md Поясни цей файл простою мовою для маркетолога.
```

## Часті помилки

- Не вказали файл — Agent шукає сам (довше і може помилитися)
- Надто багато @ одночасно — переповнення контексту
