# Cloud Agents — агенти в хмарі

## Простими словами

Cloud Agent — це Agent, який працює не в вашому відкритому Cursor, а в хмарі Cursor. Він може виконувати завдання в репозиторії, поки ваш комп'ютер вимкнений.

## Коли це потрібно

- Довге завдання на окремій гілці
- Робота через GitHub
- Фонова автоматизація
- Командна розробка

## Що важливо новачку

Спочатку освойте звичайний Desktop Agent. Cloud Agents потребують розуміння Git, гілок, секретів і окружень.

## Покроково

1. Підключіть репозиторій
2. Відкрийте Cloud Agents на сайті Cursor
3. Дайте завдання з чітким результатом
4. Перевірте diff/PR
5. Не кладіть секрети в репозиторій
