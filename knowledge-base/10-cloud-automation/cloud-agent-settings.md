# Cloud Agent Settings

## Простими словами

Cloud Agent Settings — налаштування того, як хмарні агенти працюють з репозиторіями, окруженнями, секретами і командними правилами.

## Коли вам це потрібно

- Cloud Agent не бачить потрібний репозиторій
- Потрібні environment variables
- Потрібно обмежити доступи
- Команда хоче єдиний режим роботи

## Що важливо новачку

Секрети не можна зберігати в Git. Все, що схоже на API key, token, password, повинно жити в захищених налаштуваннях, а не у файлах проєкту.

## Міні-чеклист

- Репозиторій підключений
- Гілка вибрана правильно
- Secrets задані в безпечному місці
- Rules/skills доступні Cloud Agent
- Після запуску перевіряється diff/PR
