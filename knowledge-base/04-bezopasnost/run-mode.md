## Простими словами

**Run Mode** — налаштування, чи може Agent запускати команди в терміналі і з якими обмеженнями.

## Режими (спрощено)

| Режим | Для новачка |
|-------|-------------|
| **Auto-review** | Рекомендується: питає перед ризикованим |
| **Allowlist** | Тільки команди зі списку |
| **Run Everything** | Все без питань — **не для новачків** |

## Покроково

1. Settings → Agents (або Terminal / Run Mode)
2. Виберіть **Auto-review**
3. При появі запиту на команду — читайте і схвалюйте свідомо

## Часті помилки

- Run Everything на робочому проєкті — ризик видалення даних
- Схвалюєте команди, не розуміючи тексту — спитайте Agent «що ця команда робить?»
