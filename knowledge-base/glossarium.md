# Глосарій

| Термін | Простими словами |
|--------|-----------------|
| **Agent** | AI-помічник, який сам відкриває файли, пише код і запускає команди |
| **Ask** | Режим «тільки запитати» — дивиться, але не змінює файли |
| **Plan** | Спочатку план, ти схвалюєш — потім правки |
| **Debug** | Режим пошуку складних помилок із доказами |
| **Tab** | Сіре автодоповнення коду під час набору (як розумна підказка) |
| **Diff** | Порівняння «було / стало» — що агент змінив |
| **Checkpoint** | Знімок файлів до правки; можна відкотити |
| **Canvas** | Інтерактивний звіт/дашборд поруч із чатом (не простирадло тексту) |
| **Shared Canvas** | Опублікований canvas за посиланням для команди (тільки перегляд) |
| **Publish** | Кнопка публікації Shared Canvas на панелі canvas |
| **Rule** | Постійна інструкція для агента (стиль, мова, заборони) |
| **Skill** | Рецепт для повторюваного завдання (чеклист, workflow) |
| **Subagent** | Вузький помічник в окремому «вікні» (дослідження, shell) |
| **MCP** | Підключення зовнішніх інструментів (браузер, API, docs) |
| **Run Mode** | Як агенту дозволяти команди в терміналі |
| **Auto-review** | Безпечний режим: агент питає перед небезпечними командами |
| **Allowlist** | Список дозволених команд |
| **Terminal tool** | Інструмент Agent для запуску команд проєкту |
| **Browser tool** | Інструмент Agent для відкриття сторінок, кліків і скриншотів |
| **Search tool** | Пошук по проєкту: за змістом або точним текстом |
| **Cloud Agent** | Агент у браузері на cursor.com/agents |
| **Automation** | Запуск агента за розкладом або подією |
| **Hook** | Автоматична дія Cursor при події сесії/проєкту |
| **@file** | Посилання на файл у промпті — «дивись сюди» |
| **Контекст** | Все, що агент «пам'ятає» в поточному чаті |
| **Scope creep** | Агент роздуває завдання — робить більше, ніж просили |
| **Human-in-the-loop** | Людина перевіряє результат AI — це норма |
| **Frontmatter** | Службовий блок `---` на початку .md файлу |
| **globs** | Шаблон шляхів файлів (наприклад `**/*.md`) |
| **alwaysApply** | Правило діє в кожному чаті |
| **Task** | Виклик субагента з головного агента |
| **Explore** | Вбудований субагент для пошуку по проєкту |
| **Bash** | Вбудований субагент для команд терміналу |
| **Browser** | Вбудований субагент для роботи з веб-сторінкою |
| **IDE** | Середовище розробки — програма, де ти працюєш з кодом |
| **Репозиторій / папка проєкту** | Папка з файлами, яку ти відкрив у Cursor |
| **Промпт** | Твоє повідомлення агенту — завдання |
| **Модель** | Який AI «мозок» використовується (GPT, Claude тощо) |
| **Ліміт контексту** | Скільки тексту вміщується в одному чаті |
| **Enterprise API** | API для команд — не потрібен у перший день |
| **SDK** | Бібліотека для запуску Cursor із власного коду |
| **CLI** | Управління Cursor з командного рядка |
| **Bugbot** | Автоматичне ревью багів у pull request |
| **Security Agent** | Перевірка коду на ризики безпеки |
| **Integration** | Підключення GitHub, Slack, Linear та інших сервісів |
