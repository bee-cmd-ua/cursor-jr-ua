# Типові проблеми новачків Cursor

## Не бачу Agent

**Суть:** Agent може бути прихований, відкрито не той режим або не та панель.

Що зробити:

1. Відкрийте чат/Agent через інтерфейс Cursor
2. Перевірте режим: Ask, Plan, Agent або Debug
3. Відкрийте папку проєкту, а не один випадковий файл

## Не розумію diff

**Суть:** зелене — додано, червоне — видалено.

Уявіть редактора, який показує правки в документі до прийняття.

Що зробити:

1. Не приймайте diff одразу
2. Попросіть Agent пояснити кожну групу змін
3. Приймайте тільки зрозуміле

## Агент усе зламав

**Суть:** спочатку дивимось diff/checkpoint, потім виправляємо.

Що зробити:

1. Не запускайте нові великі завдання
2. Знайдіть checkpoint перед правкою
3. Попросіть пояснити, які файли були змінені
4. Відкотіть або попросіть мінімальний фікс

## Боюся терміналу

**Суть:** термінал — це пульт проєкту, але новачку не потрібно тиснути все підряд.

Що зробити:

1. Просіть Agent спочатку пояснити команду
2. Не погоджуйтесь на видалення файлів без розуміння
3. Для небезпечних команд питайте: «що зміниться і як відкотити?»

## MCP не з'явився

**Суть:** часто потрібен перезапуск Cursor, правильний config і секрети.

Що зробити:

1. Перевірте, куди додано MCP config
2. Перевірте API keys/env
3. Перезапустіть Cursor
4. Спитайте Agent: «які MCP tools доступні?»

## Немає Publish/Share у Canvas

**Суть:** кнопка може бути не у файловому `.canvas.tsx`, а у Canvas, створеного/відкритого в інтерфейсі; ще впливають тариф, team і Privacy Mode.

Що зробити:

1. Відкрийте Canvas як canvas у Cursor
2. Шукайте `Publish`, не звичайний `Share`
3. Перевірте team/тариф
4. Перевірте, чи не увімкнено Legacy Privacy Mode

## Agent просить забагато прав

**Суть:** це момент зупинитися і перейти в Plan/Ask.

Що зробити:

1. Попросіть пояснити ризик
2. Попросіть розбити завдання на маленькі кроки
3. Дозволяйте тільки зрозумілі дії
