# Cursor за 7 днів

Міні-курс для людини без розробки. Кожен день — один результат, не теорія заради теорії.

## День 1 — відкрити Cursor і не боятися

**Результат:** відкрита папка, Agent пояснив проєкт.

Промпт:

```text
Я новачок. Поясни цю папку простою мовою: що тут головне і які 3 файли відкрити першими. Поки нічого не змінюй.
```

## День 2 — Agent і diff

**Результат:** одна маленька правка і розуміння зеленого/червоного diff.

Промпт:

```text
Запропонуй одну безпечну правку для тренування. Спочатку поясни, що зміниш, і чекай мого підтвердження.
```

## День 3 — Ask, Plan, Debug

**Результат:** користувач розуміє, який режим обрати.

- Ask — запитати і подивитися
- Plan — спочатку узгодити план
- Agent — зробити
- Debug — знайти причину помилки

## День 4 — Rules

**Результат:** перше правило поведінки для Agent.

Приклад:

```text
Завжди відповідай мені українською і пояснюй складні дії простими словами.
```

## День 5 — Skills

**Результат:** розуміння, що skill — це рецепт повторюваної роботи.

Приклад: «кожного разу перевіряй SEO-текст за одним чеклистом».

## День 6 — MCP

**Результат:** розуміння MCP як «перехідника» до зовнішніх сервісів.

Не підключай одразу всі. Почни з одного сервісу і одного тестового виклику.

## День 7 — Canvas і автоматизація

**Результат:** перший візуальний звіт або простий automation-план.

Промпт:

```text
Зроби Canvas-звіт про те, чого я навчився в Cursor за тиждень: що вмію, що ще налаштувати, які ризики.
```

## Фінальна перевірка

- Я розумію, коли використовувати Ask/Plan/Agent/Debug
- Я бачив diff і можу відкотити checkpoint
- Я знаю різницю між rule, skill, subagent і MCP
- Я не даю агенту небезпечні дії без перевірки
