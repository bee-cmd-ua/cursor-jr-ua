## Простими словами

Офіційний курс: як формулювати завдання, давати контекст і не роздувати scope.

## Ключові ідеї

1. **Обв'язка:** Instructions + Tools + Model
2. **Промпт з @file** — вказуйте файли явно
3. **Scope creep** — ріжте завдання на частини
4. **Human-in-the-loop** — ви перевіряєте результат

## Ефективний промпт (шаблон)

```
@шлях/до/файлу
Мета: [одне речення]
Обмеження: не чіпати [X]
Перевірка: [як зрозуміти що готово]
```
